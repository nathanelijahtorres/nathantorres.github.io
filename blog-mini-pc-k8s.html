Running Lightweight Kubernetes in a Mini-PC Cluster

I built a mini-PC cluster to practice Kubernetes operations in a setup that feels close to real infrastructure. I chose a lightweight distribution to keep resource usage predictable while still learning production-grade concepts.

The cluster became my testbed for deployment rollouts, health probes, ingress routing, and persistent storage experiments. I also rehearsed node maintenance tasks like draining and rejoining nodes to understand how workloads behave during planned changes.

This project helped me connect system administration fundamentals with DevOps workflows. It improved how I reason about infrastructure lifecycle, service reliability, and repeatable deployment practices.
